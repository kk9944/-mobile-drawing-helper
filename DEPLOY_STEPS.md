# GitHub Pages 部署步骤

当前仓库：

```text
https://github.com/kk9944/-mobile-drawing-helper
```

## 上传文件

把这些文件放到仓库根目录：

```text
index.html
styles.css
app.js
README.md
server.mjs
.nojekyll
```

## 开启 GitHub Pages

进入仓库页面后：

```text
Settings -> Pages -> Deploy from a branch -> Branch: main -> Folder: /root -> Save
```

等待 1-3 分钟后访问：

```text
https://kk9944.github.io/-mobile-drawing-helper/
```
